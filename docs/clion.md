# Développer le TCO

Ouvrir le projet Gradle dans IntelliJ IDEA avec JDK 21. Lancer `desktopTest`
pour les tests, `run` pour l'interface et `prepareRelease` pour les paquets.
Les anciennes configurations CLion/CMake/Qt ont été retirées. CLion reste
utile pour maintenir les composants natifs du dépôt SDK.
